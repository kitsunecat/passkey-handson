# お題5：UVフラグと二要素認証

## 目的

「パスキーなら追加の二要素認証は不要」と判断できる根拠と、その限界を考える。

## 講演との対応

意思決定4（パスキーと二要素認証）。UV（User Verified）フラグは認証器の自己申告である点。

## AIへの指示例

> `user_verification` を required と preferred で切り替えられる設定を追加し、ログイン結果画面に UV フラグの値を表示して。required のときは、UV なしの認証ではログインを拒否して

## 確認方法

仮想認証器で「Supports user verification」をオフにし、

- preferred ではログインできる
- required では拒否される

ことを確認する。そのうえで「UV なしでログインできることをどう考えるか」を議論する。

> ブラウザは `user_verification: "required"` のとき、UV に対応していない認証器を候補から外すことがあります。サーバー側でも UV フラグを検証していることは、ログ（`[passkey]`）とテストで確認できます。
