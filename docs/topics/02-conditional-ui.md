# お題2：Conditional UI（オートフィル）

## 目的

ボタン方式とオートフィル方式の体験の違いを比べる。

## 講演との対応

意思決定3（UX設計）。SmartHR はオートフィルとボタンを併用し、以前パスキーでログインした人にだけ、ページを開いた瞬間に候補を出している。

## AIへの指示例

> ログイン画面にメールアドレス欄を追加し、Conditional UI（`mediation: "conditional"` と `autocomplete="username webauthn"`）でパスキーを候補に出して。
> 発展：パスキーでログインしたら localStorage に記録し、記録がある人にだけ autofocus して

## 確認方法

- 入力欄をクリックするとパスキーが候補に出て、選ぶだけでログインできる
- 発展：一度パスキーでログインした後に再訪すると、クリックしなくても候補が出る

> 仮想認証器では、オートフィルの候補が表示されず、すぐにログインまで進むことがあります。本物の認証器（Touch ID など）でも試してみてください。
